# Add IPGEOLOCATION_API_KEY to Vercel

The Environment Variables page is now open in your browser.

## Steps:

1. **Key**: Enter `IPGEOLOCATION_API_KEY`
2. **Value**: Paste your ipgeolocation.io API key
3. **Environments**: Check all three:
   - ✅ Production
   - ✅ Preview
   - ✅ Development
4. Click **"Save"**

## After Saving:

Vercel will automatically redeploy with the new environment variable. The deployment should complete in about 2-3 minutes, and your location detection will work perfectly!

## Your ipgeolocation.io API Key

You can find your API key at: https://app.ipgeolocation.io/dashboard
